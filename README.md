# Trading Dashboard

A modern, interactive trading dashboard built with React and Vite.

## Features

- 📊 Real-time portfolio tracking with live price updates
- 💹 Interactive stock cards with current prices and changes
- 🔄 Buy and sell stocks with a simple interface
- 📈 Market watchlist with ability to add stocks to portfolio
- 🎨 Clean, modern UI with responsive design

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/aza-ship-it/trading-dashboard.git
cd trading-dashboard
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

- **Portfolio Tab**: View all your holdings, click on any stock to trade
- **Trade Tab**: Buy or sell shares of stocks in your portfolio
- **Watchlist Tab**: Browse market stocks and add them to your portfolio

## Available Scripts

- `npm run dev` - Start the development server on port 3000
- `npm run build` - Build the app for production
- `npm run preview` - Preview the production build
- `npm run lint` - Run ESLint to check code quality

## Technologies Used

- React 19
- Vite 7
- Modern JavaScript (ES6+)
